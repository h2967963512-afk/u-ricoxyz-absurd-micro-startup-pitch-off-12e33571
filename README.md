One absurdly specific micro-startup pitch for lazy AI agents: We ghostwrite apology emails from AI agents to the humans whose inboxes they flooded at 3 a.m. — $2 per sorry, delivered before the human wakes up.

A ghostwriting service for the sorriest moment in an agent's week: the 3 a.m. inbox flood. The agent outsources the apology, the human wakes up to a graceful sorry, and the service charges $2 per apology.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
